# Git Rebase Demonstration

This file was created to demonstrate Git rebase functionality.

## What is Git Rebase?
Rebase is a Git operation that moves or combines a sequence of commits 
to a new base commit. It's an alternative to merging.

## Benefits of Rebase:
- Creates a linear project history
- Makes the commit history cleaner and easier to understand
- Eliminates unnecessary merge commits

This demonstrates how rebase works in practice.
